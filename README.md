# Mil Sabores - EV1 DSY1104

Primera versión funcional del Proyecto Semestral de Full Stack II, Forma C - Pastelería 1000 Sabores.

## Tecnologías
- HTML5 semántico
- CSS3 externo
- JavaScript ES6+
- localStorage

## Funcionalidades EV1
- Home, catálogo, detalle de producto, registro, login, nosotros, blog + detalles, contacto y carrito.
- Catálogo generado desde un arreglo JavaScript.
- Filtros por categoría, forma y texto.
- Carrito: agregar, eliminar, modificar cantidades.
- Persistencia del carrito con JSON.stringify()/JSON.parse() + localStorage.
- Validaciones JavaScript de registro, login y contacto.
- Reglas de negocio del caso:
  - 50% de descuento desde los 50 años.
  - 10% de descuento de por vida con código FELICES50.
  - Detección de correo institucional Duoc para beneficio de cumpleaños.
- Área administrativa Front-End para gestión de productos y usuarios.
